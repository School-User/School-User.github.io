CyberPatriot

The national youth cyber defense competition: given a deliberately misconfigured Windows or Linux image, find and fix as many real vulnerabilities as possible before the clock runs out — without breaking the services that are supposed to keep running.

Windows HardeningLinux HardeningForensicsTeam Competition

What the competition actually asks

CyberPatriot rounds hand teams a set of virtual machine images that look like real, in-use systems — except they've been deliberately broken: weak or shared passwords, unnecessary services left open, missing patches, malicious scheduled tasks and startup items, backdoor user accounts, misconfigured firewall rules. The job is to find and fix as many of those issues as possible inside a fixed time window, scored automatically as changes are made, while specific "critical services" (things like a web server or file share the scenario says must keep running) have to stay up the whole time. Breaking a required service costs points just like missing a vulnerability does — hardening too aggressively is its own failure mode.

Rounds also include short answer forensics questions worked into the same scenario — things like identifying a suspicious log entry or explaining why a particular configuration is dangerous — so it's not purely mechanical checklist work.

What that actually trains

Compared to a lot of security learning that happens in isolated labs, CyberPatriot's format forces a specific discipline: work fast, verify every change against the live scoring feedback instead of assuming a fix landed, and keep required services running the whole time. That maps closely to real defensive security work, where "did my hardening change actually break production" is as important a question as "did it fix the vulnerability."

Where it connects to the rest of what I build

A lot of my other projects are the opposite motion — reverse-engineering and getting into systems rather than locking them down. CyberPatriot is the complementary skill: understanding a system well enough to see where it's weak, from the defender's side instead of the attacker's.
