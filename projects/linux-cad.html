LinuxCAD

Fusion 360 didn't have a Linux version, so I built a parametric CAD app for Linux myself. You sketch, extrude, fillet and cut, and every step stays editable in a timeline.

PythonPySide6OpenCascadeSolveSpaceSTEPAppImage

The goal

I wanted a Fusion-style workflow on Linux: sketch on a plane, extrude it, and go back to change a dimension without rebuilding everything. Nothing on Linux did that the way Fusion does. So LinuxCAD is a from-scratch app with the same layout: a 3D viewport with a ViewCube, a browser tree, and a feature timeline along the bottom.

How it's built

The geometry kernel is OpenCascade, the same family of kernel behind many open CAD tools, and it handles the solids, booleans, fillets, chamfers and shells. Sketches use SolveSpace's constraint solver through python-solvespace, so the solver keeps every constraint satisfied while you drag points around. The UI is PySide6. The OpenCascade viewer embeds through X11, so on Wayland it runs under XWayland.

Sketching

Lines, rectangles, circles and 3-point arcs, with nine constraints (coincident, horizontal, vertical, parallel, perpendicular, equal, midpoint, concentric, fixed) and a tangent constraint. Dimensions are live. The status bar shows how many degrees of freedom are left, and a constraint that would over-constrain the sketch is refused instead of silently breaking the drawing.

Solids, with a timeline

Extrude picks closed regions automatically and can create a new body, join to what it touches, or cut. Revolve, fillet, chamfer and shell are there too. Every sketch and feature is a step in the timeline, and the model is rebuilt by replaying those steps. Double-click an early sketch and everything after it updates. A rollback marker lets you step back through history. If a step can no longer compute, for example because its profile was deleted, it turns red and tells you why.

Features remember the edges and faces they were applied to by a point on each one, so making a block taller keeps its fillets in the right place.

Tracing a drawing

You can drop in a reference image, calibrate it by clicking two points on a dimension you know, and then trace over it with sketches that carry exact dimensions. The image is saved inside the design file, so a .lcad file stays self-contained.

Test case: a forklift fork

To check that the app is accurate, I rebuilt a forklift fork from a Fusion drawing: 13" × 3.5", a 1.25" tab, 0.5" chamfers, an R2.11 notch and 0.25" thickness. The model matches the drawing, and a test checks it against a separate hand calculation of the same dimensions.

Shipping it

There's an AppImage build that bundles Python, Qt and OpenCascade into one file. It's compiled in a manylinux container, so it runs on any distro with glibc 2.34 or newer. You can open STEP files, save and open native .lcad designs, and export STEP and STL.

Status

The planned milestones are done: the viewport, sketches, extrude, the parametric timeline, solid features, native file save and open, the forklift rebuild, and the canvas tracing tool. The source is in a private repo for now.
